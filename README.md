# 银幕质检 · Screen QA

记录影片画面、声音、字幕经过真实影院 DCP 放映链路后的实际效果，以及 DCP 制作、字幕工作流与大连本地信息。

Recording how picture, sound, and subtitles actually behave after going through a real cinema DCP projection chain — plus DCP authoring, subtitle workflows, and Dalian local info.

**站点 / Site**：https://dutlwz.github.io/dalian-screen-notes/

## 栏目 · Sections

| 栏目 Section | 内容 |
|---|---|
| 验证记录 Verification | 影片在真实影院 DCP 放映后的画面/声音/字幕验证结果 |
| DCP 制作 | OV/VF 制作、字幕封装、合规性 |
| 字幕工作流 | SRT/ASS/PGS 等不同字幕格式的处理 |
| 大连影院 | 支持 DCP 试映与验证的影院信息（大众点评指路） |
| 大连社区 | 桌游等本地兴趣社区 |
| 个人分享 | 美食点评等个人分享 |
| 关于 | 项目说明、验证方法论、投稿指南 |
